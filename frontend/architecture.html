Design decisions

Why it is built this way.

One shared memory bank

Every agent reads and writes the same Hindsight bank per company. No agent keeps a private copy, so what one learns, all can recall. We use Hindsight rather than building memory infrastructure ourselves.

Failures are first-class

Records keep what was tried and failed, not just what worked. The Verifier reads raw records and can veto a diagnosis that contradicts them, up to three revision rounds.

Never invent a source

If memory has nothing, the reply says so and offers clearly labelled general guidance. Answers carry a support level: well supported, partly supported, or not proven.
