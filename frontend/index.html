the crew

Four agents. One shared memory.

They talk in a Band room, read and write the same Hindsight bank, and every recommendation links back to the exact visits behind it.

Dispatcher

Remote fix or send a technician? Only reset, setpoint and log reading go remote, and never a fix that already failed here.

“Last 5 remote resets: 0 worked.”

Diagnostician

Recalls this machine, its model family and the site, then says how sure it is: n, verified rate, interval. Under 5 attempts is a weak signal.

“n=4, 3 verified. Weak signal.”

Parts

Decides what goes in the van from past fixes on comparable units, and flags what is not on the shelf.

“Inverter board: 1 left.”

Verifier

Sees only the raw visit records, never the other agents’ reasoning. Deterministic checks, temperature zero, and it can veto.

“Citation not in the records. No.”
how Hindsight is used

It learns, and it knows what it has not proven.

Real retain, recall and reflect, not a vector database with a nice name.

1

Retain

Every visit is stored with the suspected cause, what was tried, and a verified outcome. Follow-ups are retained as they fall due, so the bank learns that a fix held, or came back.

2

Recall

Before each decision the agents recall with tags that must all match: this machine, this family, this kind of record. Alarms never leak into a diagnosis.

3

Reflect

When recent evidence contradicts an old lesson, the belief is corrected, retained back to the bank, and shown in the briefing: Belief updated.
